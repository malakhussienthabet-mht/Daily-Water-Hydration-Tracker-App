# 💧 Daily Water & Hydration Tracker App

تطبيق عملي مبني باستخدام **Flutter & Dart** لحساب وتتبع الاحتياج اليومي التقديري من الماء بناءً على الوزن وساعات النشاط البدني، بتصميم عصري وجذاب بنظام الألوان الداكنة (**Dark Theme**).

---

## 📱 مميزات التطبيق

1. **تصميم عصري (Dark UI):**
   - ألوان مخصصة ومريحة للعين متناسقة مع هوية التطبيق (خلفية كحلية داكنة `#0A0E21` ولمسات سماوية `#00E5FF`).
   - حواف دائرية وبطاقات تفاعلية أنيقة.

2. **الشاشة الأولى (Input Screen):**
   - **اختيار الجنس:** بطاقتان تفاعليتان (`Male` و `Female`) مع تغيير لون الإطار والبطاقة عند التحديد.
   - **مستوى النشاط البدني:** شريط تمرير (`Slider`) لاختيار عدد ساعات النشاط اليومي (من 0 إلى 8 ساعات) مع عرض القيمة في الوقت الفعلي.
   - **الوزن والعمر:** بطاقات تحكم بالوزن والعمر مع أزرار دائرية (`+` و `-`) مدعومة بالتحقق من الحدود:
     - الوزن: الحد الأدنى 30 كجم، والحد الأقصى 200 كجم.
     - العمر: الحد الأدنى 10 سنوات، والحد الأقصى 100 سنة.
   - **زر الحساب:** زر عريض أسفل الشاشة (`Calculate Water Intake`) ينقل المستخدم إلى شاشة النتيجة عبر `Navigator.push`.

3. **الشاشة الثانية (Result Screen):**
   - **بطاقة النتيجة المركزية:** تعرض كمية الماء اليومية التقديرية باللتر مع أيقونة الماء (مثل: `2.95 L / Day`).
   - **توضيح التقدير:** تنبيه بأن القيمة تقديرية لأغراض تعليمية وليست نصيحة طبية شخصية.
   - **نص توجيهي ذكي (Dynamic Guidance):** يعتمد على نتيجة الحساب لتوجيه المستخدم بلباقة وحيادية:
     - أقل من 2.0 لتر: تقدير منخفض نسبياً، توزيع الشرب على مدار اليوم.
     - من 2.0 إلى 3.0 لتر: تقدير متوسط، شرب الماء على فترات منتظمة.
     - أكثر من 3.0 لتر: تقدير مرتفع نسبياً بسبب النشاط أو الوزن.
   - **ملخص المدخلات (Input Summary):** عرض ملخص لبيانات المستخدم المدخلة (الوزن، العمر، النشاط، الجنس).
   - **زر إعادة الحساب (`Re-calculate`):** للرجوع بسلاسة للشاشة السابقة عبر `Navigator.pop`.

## 📐 المنطق البرمجي والمعادلة الحسابية

المعادلة مبسطة لأغراض التدريب والتعليم:
```dart
baseMl = weightKg * 35;           // الاحتياج الأساسي (35 مل لكل كجم)
activityMl = activityHours * 250; // الاحتياج الإضافي للنشاط (250 مل لكل ساعة)
totalMl = baseMl + activityMl;     // المجموع بالمليلتر
litres = totalMl / 1000;          // التحويل إلى لتر
```

## 🧩 الـ Widgets المطبقة في المشروع

- **MaterialApp & Scaffold:** بناء الهيكل الأساسي وتطبيق الـ Dark Theme الموحد.
- **AppBar:** شريط العنوان مع أيقونة قطرة الماء وأزرار التنقل.
- **SafeArea & SingleChildScrollView:** لحماية المحتوى ومنع حدوث مشاكل الـ `RenderFlex overflow`.
- **Column & Row:** ترتيب العناصر رأسياً وأفقياً.
- **Expanded & Flexible:** توزيع المساحات بتوازن وتجاوب.
- **Container & Card:** بناء البطاقات المربعة وتطبيق التنسيقات والحواف الدائرية والظلال.
- **GestureDetector & InkWell:** التقاط نقرات المستخدم على بطاقات الجنس والأزرار.
- **Slider & SliderTheme:** شريط اختيار ساعات النشاط وتخصيص ألوانه.
- **ElevatedButton & IconButton:** الأزرار العريضة السفلية وأزرار الزيادة والنقصان.
- **Navigator (push & pop):** الانتقال وتمرير البيانات بين الشاشات والعودة بسلاسة.

## 🚀 طريقة التشغيل (How to Run)

1. تأكد من تثبيت بيئة عمل Flutter:
   ```bash
   flutter doctor
   ```
2. تثبيت الحزم والمكتبات:
   ```bash
   flutter pub get
   ```
3. تشغيل التطبيق على المحاكي أو جهازك:
   ```bash
   flutter run
   ```
4. تشغيل الاختبارات للتأكد من صحة الحسابات:
   ```bash
   flutter test
   ```
